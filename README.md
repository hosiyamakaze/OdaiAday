# お題を出して記憶を強化する(日本語説明)
- 例として図書目録を含む特定のフォルダ内のテキストファイルから任意の1行を取り出して「今日のお題」とする。
- お題はポップアップウインド、イベントログ、メールする
## PowerShellスクリプト「OdaiAday.ps1」
- ファイル名は”著者『書籍』.txt”を仮定する 
- 所定回リトライして選択できない場合は”目次がありません”とする 
1. フォルダ内の.txtファイルをランダムに1つ選択 
2. ファイル内容を2行以上の空行でブロック分割 
3. “読了”を含むとき”既読”とする 
4. “目次”を含むブロックからランダムに1行選択 
5. ファイル名(拡張子除く)、既読/未読、目次項目をイベントログに記録 
6. 同内容をダイアログ表示 
7. 同内容をE-mail(携帯等へ)  

## タスクスケジューラ
1. 定時にPowershell.exeにより上記スクリプトを実行する

## イベントログ
1. イベントソース「OdaiAday_ps1」をカスタムビューにする
